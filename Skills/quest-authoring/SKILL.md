# Quest authoring

For the RC1 canonical slice:

1. Read the project contract before proposing a draft.
2. Preserve the confirmed requirements exactly.
3. Never invent NPC or item identifiers.
4. Do not add hidden prerequisites.
5. The only supported RC1 flow is level gate → NPC → collect item → return → one-time gold reward.
6. If the request exceeds that capability, report the unsupported requirement instead of fabricating a draft.
7. A draft is only a proposal. It cannot approve or apply itself.
